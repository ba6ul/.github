# .github

Personal source of truth for how I manage my repositories: labels, templates,
shared workflows and helper tooling. For my own repos; not a project for
outside contributors.

- [`WORKFLOW.md`](WORKFLOW.md): the lifecycle, rules, and the PR wording contract
- [`labels/vocabulary.json`](labels/vocabulary.json): the label vocabulary
- [`docs/project-config.md`](docs/project-config.md): the per-repo `.github/project.json`
- `templates/`, `examples/`, `schema/`: supporting files

Nothing here applies to another repo until that repo is adopted on purpose.
